# M5 developer-experience usability gate

## Purpose

M5 closes with a scripted, clean-environment journey proving the CLI,
template, examples, typed routes, testing tools, and documentation work
for someone WITHOUT maintainer knowledge — consuming packed artifacts,
not workspace state. Governed by the [release-gate
standard](../../engineering/release-gates.md) and the [GH-081
issue](../../issues/m5/gh-081-run-the-m5-developer-experience-usability-gate.md).

## Required dependencies

All M5 issues complete with checked acceptance criteria, merged
commits, durable transcripts, and closed GitHub issues: GH-070 (CLI
framework), GH-073 (route manifests/typed URLs), GH-074 (test client),
GH-072 (dev command), GH-071 (create-bundar), GH-075 (starter
template), GH-076 (Todo reference), GH-077 (Admin CRUD reference),
GH-078 (migration linter), GH-079 (generated API reference), GH-080
(guides).

## Toolchain and environment profile

Bun `1.4.0`; TypeScript `6.0.3`; htmx 2.0.10 (stable) and
4.0.0-beta6 (experimental — no GA claim); Linux x86_64. Raw journey
output and measurements: [`artifacts/dx/m5-report.md`](../../artifacts/dx/m5-report.md)
and the [GH-081 verification transcript](../../evidence/gh-081/verification-transcript.md).

## The cleanroom journey (`bun run test:dx-cleanroom`)

1. Packs all seven @bundar packages into a local registry and rewrites
   workspace specs to `file:` tarball links (the documented pre-publish
   transform; `bun pm pack` rewrites `workspace:*` to a bare `0.0.0`
   which would hit the public registry — the cleanroom covers both
   forms).
2. Generates an app with create-bundar pointing every dependency at
   the PACKED tarballs.
3. Executes and MEASURES: install → typecheck → test → build →
   routes:generate → routes:check → START with live HTTP assertions
   (health, no-JS PRG, enhanced fragment, 422 with a clear field
   message).
4. Deliberate-error diagnostics: renaming a named route makes
   routes:check fail naming the stale artifact and the regenerate
   command — the clarity bar.
5. Writes the measured report; cleans everything up. 17 steps, all
   green, exit 0.

## Acceptance findings

- **Packed artifacts, not workspace imports**: the journey's app
  resolves every @bundar dependency from tarballs (verified by
  `node_modules` presence and the full green chain).
- **Deliberate errors are fixable from diagnostics**: route drift and
  validation failures produce actionable, file-naming messages
  (asserted in the journey).
- **Both dialect paths documented; v4 experimental**: getting-started
  + migration guides, CI-enforced no-GA phrasing (GH-080 tests).
- **No hidden globals or unpublished packages**: only public npm
  (@types/bun, typescript) beyond the packed registry.
- **Real defects the gate found and fixed**: the scaffolded app lacked
  a default export (route generation failed) and named routes (no
  drift detection) — both fixed in the create-bundar template and
  re-verified across the scaffold/template/guide batteries.
- `test:pack-consumers` verifies all 8 packed manifests; the full suite
  (824 tests) and every standard check pass.
