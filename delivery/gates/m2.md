# M2 server-JSX gate

## Purpose

M2 closes with maintainers accepting the server-only JSX renderer — runtime,
escaping, documents, components, async, raw-HTML trust boundary, typed
attributes, response/streaming integration, and the conformance/security/
snapshot coverage — as the stable rendering foundation for templates and
HTMX rendering work. Governed by the [release-gate
standard](../../engineering/release-gates.md) and the [GH-038
issue](../../issues/m2/gh-038-run-and-record-the-m2-server-jsx-gate.md). The
performance half of the record is the [M2 performance and memory
gate](m2-performance.md) (GH-037). No HTMX protocol compatibility claim is
made here (M3's scope).

## Reviewed policies and limitations

- **Raw HTML call-site policy**: `raw()` is the only trust path, branded by
  an unforgeable symbol (GH-031); every call site is enumerable via
  `security:raw-html-audit` (review tool — raw usage is legal and listed,
  never hidden). Unbranded strings always escape. The 13-payload corpus
  (`security:jsx`) proves breakouts (`</title>`, `</textarea>`, `</style>`,
  `</script>`) are neutralized in-process and in a real browser.
- **Streaming limitations** (recorded, from GH-034/037): streaming costs
  ~3× buffered rendering for large async lists (documented price of
  incremental first-byte delivery); non-signal-aware child promises run to
  their own settlement after cancellation (platform limit — production
  stops and settles observably); after the first flush the status line is
  committed and mid-stream errors cannot become a replacement status
  (`StreamRenderError.bytesWritten` states which world you are in).
- **Renderer parity is absolute**: sync, async, and streaming renderers are
  byte-pinned per gate run (parity pre-checks in the benchmark and property
  tests). The M2 gate cycle caught and fixed a real async-renderer
  divergence (void-element closing tags; raw-text serialization).

## Approved public surface (M2 exit)

- @bundar/jsx (zero runtime dependencies): the JSX runtime (`jsx`, `jsxs`,
  `jsxDEV`, `Fragment`), rendering (`renderToString`, `renderToStringAsync`,
  `renderToStringAuto`, `renderNode`), streaming (`renderToStream`,
  `streamResponse`, `StreamRenderError`, `RenderCancelledError`),
  responses (`fragment`, `page`), documents (`document`), the trust boundary
  (`raw`, `isRawHtml`), escaping/attribute primitives, typed stable htmx
  attributes + the `HtmxExperimentalAttributes` augmentation point, forms
  helpers (`ErrorSummary`, `CsrfInput`), and the intrinsic element map.
- @bundar/core surface unchanged since the M1 gate (61 → 71 exports through
  M4 work already merged); snapshots byte-checked by `api:check`
  (`artifacts/api/core.md`).
- Dependency direction (frozen, ADR-0016/0017): core and jsx import nothing;
  htmx → jsx; schema → core; security → core; nothing imports schema or
  security except applications. Machine-enforced (8 rules).

## Acceptance findings

- **No React/hydration dependency or browser lifecycle exists** — jsx
  imports no package (pack:inspect + architecture check); server-only by
  construction (ADR-0004/0012); browser event handlers fail closed
  (`onClick` typed to a diagnostic string, runtime rejects).
- **Escaping/security suites pass** — corpus audits, property invariants,
  and the real-browser comparison all green inside the 37-step battery.
- **Core/JSX dependency direction remains valid** — architecture check +
  boundary unit tests green.
- **Performance evidence and known limitations recorded** —
  [m2-performance.md](m2-performance.md) (baseline table, budgets,
  streaming trade-off) and the transcript above.
- Nothing skipped, nothing downgraded: every step exit 0; defects found
  during the M2 cycle (async void-element divergence, RCDATA display
  corruption, body-parser timeout acceptance) were fixed in their issues,
  not bypassed.

## Accepted residual risks

- Single-machine performance baselines (raw samples retained; budgets have
  variance headroom; GH-083 re-runs).
- Streaming costs ~3× buffered for large async lists (documented; use
  buffered rendering where first-byte latency does not matter).
- Exotic HTML tags fall back to loose `jsx()` typing (runtime renders any
  tag); the intrinsic map covers common HTML.
- `hx-trigger`/`hx-headers`/`hx-sync` attribute grammar validation stays
  with the dialect adapters (M3).
