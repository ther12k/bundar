# M0 — Contracts & Foundation

Freeze naming, package boundaries, API principles, repo structure, documentation validation, benchmark harness, browser harness, and project automation. No production framework behavior is claimed.

# M1 — Bun-native HTTP Core

Deliver native route compilation, duplicate detection, context, middleware, params/query/cookies, errors, response helpers, integration tests, and measured core budget.

# M2 — Server JSX

Deliver safe text/attribute rendering, fragments, sync/async components, raw trust boundary, documents, string/stream responses, typed common HTMX attributes, and renderer evidence.

# M3 — HTMX Dialects

Deliver neutral protocol types, htmx 2 and 4 adapters, assets, event/inheritance helpers, page/fragment/action responses, cache variation, update intents, browser suites, and unchanged-app fixture.

# M4 — Forms & Security

Deliver bounded forms/uploads, schema adapter, validation rendering, CSRF, cookies/sessions interface, flash messages, security headers/CSP, request limits, and adversarial tests.

# M5 — DX & Reference Apps

Deliver CLI/scaffolder, hot development, typed routes, test client, minimal/Todo/admin templates, HTMX audit, API docs, guides, and usability evidence.

# M6 — Alpha

Execute full matrices and benchmarks, audit package contents and licenses, generate SBOM/provenance, dry-run npm publishing, publish known limits, and satisfy alpha gate.

# M7 — HTMX 4 GA

Begin only after GA is verifiable. Diff upstream, update profile, run unchanged apps, publish migration evidence, decide the default through ADR, and release stable support.
